# Contributing to The Stellaar Platform

Thank you for contributing to the TSApp ecosystem.

## Development Workflow
1. Create a feature branch off `main`: `git checkout -b feature/your-feature-name`
2. Follow strict TypeScript and zero-warning linting standards: `npm run lint`
3. Run automated test suites: `npm run test`
4. Submit a clear pull request referencing the relevant tasks.

## Quality Standards
- Strict type definitions (no implicit `any`).
- Atomic, descriptive commit messages.
- Verified test coverage for new business logic.
